# zfl-42 漆线雕工坊 · 金粉领用与回库核销台

独立静态前端应用，直接打开 `index.html` 即可使用。

## 分层

规则、台账与页面分开，互不依赖：

- `js/rules.js` —— 规则层：纯函数判定（领用资格、批次冲突、24 小时、两成损耗、复核约束），只返回 `{ ok, status, code, message }`，不读写状态。
- `js/ledger.js` —— 台账层：唯一持有状态，负责事务、localStorage 持久化与幂等重放；判定全部委托规则层，冲突/校验失败一律不落库。
- `js/app.js` —— 页面层：渲染与交互；`index.html` + `styles.css` 为页面骨架与样式。

## 业务规则

- **领用**：仅「待阴干且无缺陷」的作品可领用；登记批次、净重、领用人和阴干完成时刻。每个金粉批次仅服务一张未关闭领用单（待回库/待复核），冲突返回 409 且不落库；批次核销或失效后可复用。
- **转待交付**：以该作品全部未失效领用单中最晚的阴干完成时刻为准，未满 24 小时不得转待交付（409）。
- **回库**：填写余粉、报废量与复核人；损耗 = 净重 − 余粉 − 报废，超过领用量两成转复核，否则直接核销。余粉 + 报废不得超过净重；原领用人不得复核（409）。
- **复核**：仅待复核单可复核；通过则核销，退回则回到待回库重新回库；原领用人同样不得复核。
- **失效**：胎体、纹样或缺陷变更，该作品全部未核销单立即失效；已核销单保留在台账中。
- **幂等**：领用/回库/复核均携带幂等键，重复或并发提交沿用首次结果；键与结果随台账持久化，刷新后重交仍返回首次结果。

## 页面

- 统计条：在制金粉、待回库/待复核/已核销/已失效单数、累计损耗、平均损耗率。
- 队列：待回库队列（回库登记，损耗实时试算）、待复核队列（通过/退回）。
- 台账：全部领用单明细（批次、净重、余粉、报废、损耗、领用人、复核人、状态、时间）。
- 作品看板：贴线中、待阴干、上金粉、待交付四列流转，缺陷追踪，详情弹窗可改胎体/纹样并查看该作品领用单。
- 队列、统计与台账均由持久化状态推导，刷新后一致；支持 JSON 导出。
