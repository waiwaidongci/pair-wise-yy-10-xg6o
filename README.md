# 漆线雕工坊 · 金粉领用与回库核销台

面向小型漆线雕工坊的金粉领用与回库核销系统。零第三方依赖，Node.js ≥ 18。

## 启动

```bash
npm start
# 或：node src/server.js
# 访问 http://localhost:3000
```

- 首次启动自动在 `data/ledger.json` 播种演示数据（可用 `PORT` / `DATA_FILE` 环境变量覆盖）。
- 页面「台账 → 重置为演示数据」可随时复位。

## 业务规则（全部集中在 `src/rules.js`，可独立单测）

1. **领用资格**：只有状态为「待阴干」且**无缺陷**的作品可领用金粉，否则冲突返回 409。
2. **批次独占**：每个金粉批次同一时刻仅服务一张**未关闭**领用单（未核销 + 待复核都算未关闭）；
   重复占用返回 409 `BATCH_BUSY`，**冲突不落库**。
3. **领用登记**：批次、净重、领用人，并快照作品的**阴干完成时刻**。
4. **24 小时闸门**：阴干完成未满 24 小时不得转「待交付」，提前操作返回 409（附可转时刻）。
5. **回库核销**：填写余粉、报废量、回库复核人；余粉 + 报废量不得超过净重。
6. **损耗两成线**：报废量 > 领用量 × 20% 时自动**转复核**（恰好 20% 直接核销），由第三人复核通过后核销。
7. **回避制度**：原领用人不得担任回库复核人，也不得担任复核人。
8. **变更即失效**：作品的胎体、纹样发生变更或新增缺陷时，其名下所有未关闭领用单**立即失效**并释放批次；失效单不可回库。
9. **幂等**：所有写接口支持 `Idempotency-Key` 头；同键重复或并发提交**沿用首次结果**（包括进程重启后），冲突/校验失败不记录幂等、不落库。

## 三层分离

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 规则 | `src/rules.js` | 纯函数业务判定：资格、独占、损耗线、24h 闸门、失效识别、队列与统计口径。无 I/O |
| 台账 | `src/ledger.js` · `src/seed.js` | JSON 文件原子落盘、**串行写队列**、幂等记录与在途合并、失败回滚 |
| 服务/页面 | `src/service.js` · `src/server.js` · `public/` | HTTP 事务脚本、静态页面；页面只渲染与发请求，规则以服务端为准 |

## 队列、统计与一致性

- 队列页四个泳道：可领用 / 未核销 / 待复核 / 最近失效（`GET /api/queues`）。
- 顶部统计卡：各状态单量、累计领用/回库/报废、在外金粉（`GET /api/stats`）。
- 页面每 5 秒拉取一次；台账单文件原子写（tmp + rename），浏览器刷新、服务重启后数据一致。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` `/api/queues` `/api/stats` | 台账 / 队列 / 统计 |
| POST | `/api/works` | 建作品（可指定阴干时刻或若干小时前） |
| PATCH | `/api/works/:id` | 改胎体/纹样、登记/清除缺陷、转状态（含 24h 闸门） |
| POST | `/api/batches` | 建金粉批次 |
| POST | `/api/requisitions` | 领用登记 |
| POST | `/api/requisitions/:id/return` | 回库（超两成自动转复核） |
| POST | `/api/requisitions/:id/review` | 复核通过 / 驳回重提 |

所有 POST/PATCH 均可带 `Idempotency-Key`。
